本地优先 · Wiki 原生检索

你的知识。
结构化。
在本地检索。

ZMWiki 把普通文档编译成相互链接的 Wiki 页面，再让 Agent 在你自己的 机器上搜索、阅读并跟踪这些链接。核心是一个 Python 库：默认确定性 运行，接入在线模型时保持模型无关。

核心

一条可以检查的检索链路。

没有黑盒管线。每个阶段都是小而可测试的模块，契约明确；每个回答都能 追溯到 Agent 真正读过的页面。

  • 链接页面

    稳定的 ID、路径、别名、标签和双向链接——不是匿名的文本块。

  • 双信号搜索

    元数据 BM25 与正文 BM25 确定性融合。结果只带元数据，不返回整页正文。

  • 证据感知的 Agent

    搜索结果不算证据，只有通过 wiki_read 真正打开的页面才算。

  • 度量而非断言

    离线检索指标，以及带逐步诊断的多跳评测。

功能

六个模块，一条本地闭环。

这些模块当前都已随仓库发布。浏览器工作台在 /app。

01wiki_schema.py

结构化 Wiki 页面

每个页面都有稳定 ID、路径、标题、别名、标签、来源 ID 和双向链接。页面可序列化为 JSON，并在构造时校验。

02wiki_retriever.py

元数据优先搜索

wiki_search 先按标题、别名、标签和描述匹配排序，再融合正文 BM25，只返回候选元数据，不返回整页正文。

03wiki_retriever.py

证据感知阅读

wiki_read 按输入顺序按路径取页，路径缺失会明确报错。只有真正读过的页面才进入 Agent 的证据集合。

04wiki_agent.py

有预算的多步 Agent

搜索、阅读、跟踪链接、回答。步数上限、重复动作抑制和连续协议错误上限由代码强制执行，不只靠提示词。

05wiki_compiler.py

来源可追溯的编译

WikiCompiler 通过 OpenAI 兼容接口把一份文档编译成一个结构化页面，并在页面上保留来源文档 ID。

06benchmark/

可度量的检索

离线检索指标、确定性答案评分和一个内部 26 例多跳评测，跟踪证据召回与逐步失败，不使用 LLM 裁判。这些是仓库内的诊断，不是通用准确率承诺。

工作流

从原始文本到可追溯的回答。

  1. 01

    导入

    纯文本文档或目录，通过现有摄取契约加载。

  2. 02

    编译与索引

    页面编译时保留来源；索引构建元数据与正文 BM25。

  3. 03

    搜索

    元数据优先排序，返回候选页面及分数，不返回正文。

  4. 04

    阅读

    按路径读取完整页面，页面链接成为下一步可跟踪的路径。

  5. 05

    回答

    Agent 只根据真正读过的页面回答，并把来源与模型文本分开。

Agent 循环
search→ read→ follow_links→ answer

由 max_steps、重复动作抑制和连续协议错误上限约束。

安装

是一个库，不是一个平台。

克隆仓库并以可编辑模式安装。默认安装零依赖，不需要模型或网络即可运行。

  • Python 3.10 或更新版本
  • 无运行时依赖
  • Wiki 与评测测试均离线运行

包内附带本地 HTTP 服务 （python -m zmwiki.web.server）。浏览器工作台在 /app，支持浏览、搜索、编辑、保存、导入 .txt 文档，以及带证据的多步 Agent 问答。

~/zmwiki 
$ git clone https://github.com/lip20041219/zmwiki.git
$ cd zmwiki
$ pip install -e .
$ python -m pytest tests/wiki -q

常见问题

值得问的问题。

简短回答，不做云端营销。

我的知识会被上传到云端吗？

默认不会。索引、搜索、阅读和确定性评测都在本地运行。只有你主动配置的模型调用——编译、Agent 推理或生成——会离开本机，并发送到你指定的端点。

需要 API Key 吗？

确定性 RAG 管线和离线评测不需要。编译和在线 Agent 需要 OpenAI 兼容接口。TUI 和库从环境变量或代码读取 Key；浏览器工作台在模型设置中输入，由服务端保存在本机，且不会回传到页面。静态官网永远不包含 Key。

有浏览器工作台或本地服务吗？

包内附带本地 HTTP 服务： python -m zmwiki.web.server --workspace path/to/wiki.json。 打开 /app 即可使用：页面列表、搜索、详情、创建/编辑/删除、 链接与来源、工作区保存、.txt 导入，以及带引用页面的多步 Agent 问答。

Wiki 存在哪里？

Wiki 页面保存在一个 JSON 工作区文件中。TUI 启动时加载，按 S 保存（覆盖已有文件需按两次）；文档导入会自动保存。 未提供 --workspace 时打开仓库自带的演示工作区（只读）。 评测产物是 benchmark/results/ 下的独立 JSON 文件。

支持哪些文档格式？

纯文本和 .txt 文件目录，通过现有摄取模块加载。PDF 与 Markdown 解析尚未实现。

ZMWiki 使用什么许可证？

MIT 许可证，声明于 pyproject.toml，完整文本见仓库根目录的 LICENSE。
